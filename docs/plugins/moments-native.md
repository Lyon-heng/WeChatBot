# 朋友圈发布

版本：1.2.0 · 可选插件，按需启用

[返回插件目录](README.md)

## 适合做什么

让角色按自己的人设，每天写一条朋友圈，并且**真的发出去**——不是存个草稿了事。

发布层用的是小鱼（[waaakong/xiaoyu](https://github.com/waaakong/xiaoyu)）的原生组件方案：正文编码成微信自己的 `mmsnspost` 报文，交给微信进程里已加载的组件发出，再按服务端返回的对象 ID 核对。报文格式、健康核验、单次提交、失败不重发，全部按他们的规则实现。

## 第一次配置

1. 在能力目录启用插件，授予“读取聊天历史 / 读取人设 / 独立模型生成 / 定时”权限，选择聊天范围。
2. 先设成 `mode = draft`（只写稿），跑一次 `preview` 看文案风格对不对。
3. 决定走哪条通道：
   - **原生**：电脑上有 4.2.0.13 的微信核心，并且愿意按 xiaoyu 的脚本构建、加载组件；
   - **网关**：有自建的 Pad 协议服务（支持发朋友圈），把地址、路径、令牌填上；
   - 都不具备时保持 `outbox`，只写稿。
4. 点一次 `diagnose`，确认账号、微信核心版本、组件会话三件事都对上。
5. 确认无误后再把 `mode` 改成 `publish`。

## 使用例子

- “看看朋友圈发布的状态” → `status`
- “写一条今天的朋友圈给我看看，别发” → `preview`
- “把这条定稿，我要发” → `prepare`，拿到提案与授权哈希
- 组件加载完成后：“确认发这条” → `publish-now`（需要确认参数）

## 三条通道的区别

| 通道 | 说明 |
| --- | --- |
| 原生 | 最接近“微信自己发的”，但一次加载只放行一条，需要人工授权 |
| 网关 | 可以无人值守，成败以服务端返回为准，真实内容仍建议看手机 |
| 发件箱 | 只写不发布，永远如实标记为“已存发件箱” |

原生通道**不能全自动**是组件刻意的限制：`/submit` 第二次会被 409 拒绝，防止重复发布和内容被替换。插件不绕过这条。

## 权限与数据

- 读取当前聊天历史、当前人设、独立调用模型、每日定时
- 触发条件：每天到你设置的时间；以及你自己在管理员私聊里发命令
- 数据都留在本机：`state/moments-native/`（提案、发件箱、当天计数）；组件令牌只在加载器写下的 `session.json` 里

关闭插件即停止后续调用，已有草稿保留。

## 配置选项

| 选项 | 说明 |
| --- | --- |
| 每日发布时间 | 北京时间，`00:00` 表示总结前一天 |
| 运行模式 | `draft` 只写稿；`publish` 按通道投递 |
| 发布通道 | `native` / `gateway` / `outbox` / `auto` |
| 组件会话文件 | 加载器写下的 `session.json`，留空用默认路径 |
| 发布用微信号 | 留空自动取管理员设置里的 wxid |
| 协议网关地址 / 路径 / 格式 / 令牌 | 走网关通道时填 |
| 每天最多发布条数 | 1～3，多个聊天共享同一份计数 |
| 正文长度 | 20～300 字，默认 80 |
| 额外写作要求 | 追加到生成提示词里，例如“不要提工作” |

## 常见问题

**聊天里说「小工具卡住」是怎么回事？**
宿主给插件工具的上限是 8 秒、插件调模型的上限是 25 秒，而这台机器上的模型单次生成要 30 秒以上（日志实测 31～38 秒）。所以 1.2.0 起不再让插件自己写稿，而是由聊天模型写正文、再用 prepare-text / publish-text 交给插件编码投递，几十毫秒完成。preview 这类自写工具也改成 5 秒内必返回，写不出来就直说。

**为什么提示“微信核心与组件不一致”？**
组件里的函数地址只对微信 4.2.0.13 这一个构建有效。版本不同，地址全错，组件自己也会拒绝加载。要么换成 4.2.0.13，要么按 xiaoyu 的 `scripts/build-wechat-moments.py` 为自己的核心重新推导常量并验证——后者是逆向工作，不建议在没有验收的情况下直接发真实内容。

**本机 Hook 为什么不能发朋友圈？**
Hook 只提供消息、资料、数据库接口，没有朋友圈发布路由。这也是旧版插件只能落发件箱的原因。

**发出去失败了能不能自动重发？**
不能，也不该：一次投递结果未知时重发，很可能变成两条重复动态。状态会如实记成“未确认”，请先看手机再决定。

**能发图片或指定可见范围吗？**
这一版只做公开纯文字。图片、部分可见、指定好友都还没验证，代码直接拒绝。

## 通道选择（2026-11-10 更新）

| 通道 | 能否真发 | 状态 |
| --- | --- | --- |
| `uia` 界面操作 | **能** | 已实测跑通，默认走这条 |
| `native` 原生组件 | 不能 | 缺 5 个版本常量；且继续动态追踪时客户端两次自行退出，已停 |
| `gateway` 协议网关 | 能 | 需要外部 Pad 协议服务，本机没有 |
| `outbox` 只写稿 | — | 兜底 |

`uia` 的做法：长按朋友圈相机图标 900ms 打开纯文字编辑框 → 剪贴板粘贴 → 点“发表” → 复核编辑框关闭。
不改微信任何内存与文件，最坏结果是“没点中”。注意：需要电脑解锁、微信在前台、停在“发现-朋友圈”。
