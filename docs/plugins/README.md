# 插件目录与下载

1.10.0 主包随附两项基础插件源码（人物记忆、人格工作室）并内置朋友圈原生、Muse 视频、声音工作室和表情包四个插件；基础插件新安装时准备代码但默认关闭。其他功能按需下载，已有安装的插件和设置在升级时保留。

[下载全部插件总包](https://github.com/Lyon-heng/WeChatBot/releases/download/v1.10.0/WeChatBot-plugins-all-1.10.0.zip) · 在“能力目录”点击“一键下载并导入全部插件”，也可下载后选择“导入插件总包”。已有插件跳过，新插件关闭，不自动授权聊天。
