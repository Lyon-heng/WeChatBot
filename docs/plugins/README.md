[下载全部插件总包](https://github.com/Lyon-heng/WeChatBot/releases/download/v0.5.6/WeChatBot-plugins-all-0.5.6.zip) · 在“能力目录”点击“一键下载并导入全部插件”，也可下载后选择“导入插件总包”。已有插件跳过，新插件关闭，不自动授权聊天。
