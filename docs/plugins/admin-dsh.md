# 管理员 WorkBuddy 助手

版本：1.1.0 · 可选插件，按需安装

[返回插件目录](README.md) · [下载单独插件包](https://github.com/Lyon-heng/WeChatBot/releases/download/v0.5.5/admin-dsh-1.1.0.zip)

## 适合做什么

让已授权管理员从聊天调用 WorkBuddy。

管理员在聊天或助手模式中按本聊天授权调用 WorkBuddy。用「能力查询」可以看到本聊天真实可用的 WorkBuddy 工具清单；任务由 WorkBuddy 模型在当轮直接调用已授权工具执行，没有后台任务队列，进度/结果/取消会如实说明。聊天模式保留人格和历史，默认关闭调用权限。

## 第一次配置

1. 在能力目录导入该插件，或导入总包。
2. 先在助手设置中指定管理员，并按聊天授权；仔细检查工具和任务权限。
3. 在“插件与聊天”选择具体好友或群聊，不需要的范围保持关闭。
4. 保存并检查插件状态，先用简单请求验证；升级宿主接口后按提示完整重启应用。

## 使用例子

在已授权管理员聊天中提出明确任务，WorkBuddy 会在当轮直接调用已授权工具；也可以问「现在有哪些能力」，用能力查询列出真实工具清单。

## 权限与数据

- 管理员调用 WorkBuddy 任务

关闭插件停止后续调用，已有本机数据保留。总包导入不会启用插件、放宽聊天授权或覆盖已安装插件。

## 配置选项

本插件没有独立参数；按权限和聊天范围控制。

## 限制与排查

任务可能产生文件写入或外部操作；插件不会让普通群友自动成为管理员。

- 状态“已安装，尚未启用”：检查插件总开关、权限和聊天范围。
- 状态“等待新版宿主”：准备配置后完整重启应用。
- WorkBuddy 模型或本地环境报错：先在“连接 WorkBuddy”页做连接检测，不要重复发送真实消息试错。
- 不要在公开问题报告中贴令牌、Cookie、聊天原文或私人路径。
