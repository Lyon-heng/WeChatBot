# 声音工作室：语音与音色

大型本地环境已从主包拆出，可在“语音音色 → 运行环境与组件导入”下载并直接导入 ZIP，无需手动解压。环境包不包含全部模型，导入后继续核对引擎与服务状态，详见[语音组件导入](VOICE_COMPONENTS.md)。

声音功能由“肥鱼声音工作室”插件和宿主音频服务共同提供。“语音音色”页管理声音参数、音色和引擎；“能力 → 能力目录”保留插件安装、权限和聊天范围。插件需要 storage / voice 权限，实际发微信还要求 Hook 模式与原生语音能力就绪。

## 先确认依赖

默认说话调用本机部署的 Breeze TTS 服务，也可切换到兼容 `/audio/speech` 的外接接口。宿主通过 `scripts/voice-services.ps1` 管理本机服务。

**插件 ZIP 只提供插件代码，可选语音组件也不等于全部模型。**模型、参考录音、账号音色与队列位于 `state/voice/`，不随源码或插件包发布。新电脑需要自行准备匹配环境和获准使用的模型，不能把开发机已验证当作所有安装版开箱可用。

## 语音回复与随机替换

可明确要求“用语音说晚安”。内置音色有 B 明亮可爱、A 自然可爱和温柔版，支持聊天内选择。文字长度、音频时长、发送额度和最短间隔均会限制请求；单段原生语音最长 60 秒。

“语音音色”页可开启**随机用语音替换部分句子**，设置概率与冷却。每轮最多替换一句；制作失败时补发原句文字。另有全部短回复附带语音选项，以页面提示的优先关系为准。这是“是否发语音”的随机，与“使用哪个音色”的随机分别配置。

“发送节奏”控制同一聊天的间隔、每分钟及十分钟额度。等待制作、额度和发送锁是不同阶段，不能仅凭“已生成”判断卡住。

## 自定义与随机音色

自定义音色默认折叠、首次展开加载，收起保留未保存编辑。支持新增、复制、命名、删除和选择默认。参考录音为 1–30 秒，配准确参考文字；本机整理为单声道 24 kHz WAV。

可调整语气指令、音调 0–5、语速 0.75–1.25 倍，以及音量 0.5–1.5、低音/高音 ±6 dB、响度均衡、首尾静音裁剪。本地高级生成参数包括引导强度、变化程度及种子。上传参考影响说话。

保存后可生成本机试听，不发微信。音色按账号隔离；复制可复用参考录音，删除预设保留旧任务所需文件。新任务保存音色快照，重试不重新抽取或跟随编辑变化。

“随机音色”开启后从选中的内置或自定义候选选择。外接 API 只从填有 API 音色 ID 的自定义预设随机；无有效候选则用默认 API 音色。本机编辑试听固定使用当前编辑音色。

## 本地合成与外接 API

“语音合成来源”默认本地。用户可主动切换到兼容 `/audio/speech`、返回 WAV 的接口，配置服务地址、模型、默认音色 ID 与密钥；支持根地址、含 /v1 的基础地址或完整接口地址。

外接服务会收到待合成文字，可能使用额度；本地参考录音不上传。API 音色 ID 必须由服务商实际提供，不等于上传录音克隆。仅在服务支持时发送语气 instructions。音频滤镜可本机处理，高级采样参数只用于本地引擎。

密钥用 Windows 当前账户 DPAPI 加密；留空保留，明确勾选清除才删除。切换服务不改变旧本地任务来源；外接任务绑定配置版本，变更后需新建请求，避免静默发往其他服务。接口响应大小、请求时间与 WAV 格式均受限，不代表兼容所有语音供应商。

## 默认肥鱼语音的听感

“语音音色”页的“自定义音色”提供**自然直出**预设：使用已有肥鱼参考音频直接克隆，原调、原速、CFG 1，不额外均衡。预设只填入新音色参数，不覆盖已有录音与音色；保存、试听后可设为默认。旧音色保留原参数。

Breeze 参考克隆继续保留。另外可选“原生肥鱼 CosyVoice3”独立插件：需另行准备 TTS 环境与官方肥鱼权重，启用后可在语音音色页面同文本对比或选择专用常驻引擎。发行插件 ZIP 不包含环境、权重和密钥。自然 A、自定义参考音色与外接 API 继续使用各自配置，详见 [进度与配置](P1_P2_PROGRESS.md)。

未选择自定义音色时，本地内置音色采用短中性提示词“自然清晰地说话。”与 `cfg_scale=1`，更多沿用参考录音的节奏。音色接近程度取决于参考素材和模型，不能保证与原声完全一致；限长仍为 60 秒，超限会明确失败，不截掉结尾。

调参依据：[Breeze-TTS-2.cpp v0.1.6 API](https://github.com/HoppouAI/Breeze-TTS-2.cpp/blob/v0.1.6/docs/server.md) 的默认 CFG 为 1；[Breeze 官方说明](https://github.com/breezeblue-ai/breeze-tts#usage) 区分参考克隆与风格引导。默认使用普通参考克隆，自定义音色仍可主动提高引导强度；引导越强不代表越自然。该选择需结合本机试听判断，自动测试只能验证参数和音频完整性。

参考方案：[GPT-SoVITS 的参考克隆与少样本微调](https://github.com/RVC-Boss/GPT-SoVITS)。直接克隆可减少转换环节，但自然度与声音相似度仍需分别试听，不能用耗时或测试通过数代替听感判断。语音服务的“生成本机试听”使用当前选中的默认音色；随机音色不会在此试听中随机抽取。

## 进度、取消与送达

任务显示真实的合成、编码、等待发送及回执状态，不提供虚构百分比。首次模型加载会影响耗时，本机旧测试用时不作为速度承诺。

“取消语音”用于取消本聊天尚未提交的申请；已经交给微信的动作不承诺撤回。模型工具先申请，本轮成功且未取消后才建立持久队列。账号、权限、插件代次及聊天范围变化会阻止过期申请发送。

生成完成、接口接受和服务器回执确认分别记录。请求在调用原生接口前落盘；响应丢失时核验已绑定的消息与音频摘要，不盲目重新发送。证据不足保留未确认。最终是否可播放仍以收件端为准。

## 测试与许可

本机试听不发微信；“发送测试语音”会向明确选定的已授权聊天发送，需用户主动操作。隔离回归覆盖队列、去重、权限、音色快照与外接协议；不代表所有机器或真实外接服务均验收通过。

## 独立音色页面与本地模型

侧栏“语音音色”集中管理语音组件、服务来源、参考音色和声音插件。声音插件 1.3.1 的完整设置支持本地 Breeze TTS 2 兼容 GGUF 路径，留空沿用默认模型。保存后重启语音服务才加载新路径。其他模型架构需单独引擎，可使用兼容语音 API。

“语音音色 → 选择本地声音模型”也可单独配置设备级本地模型插件，无需覆盖已有声音插件代码。此设备级插件启用时优先采用所选路径，关闭后回到声音插件原配置或内置模型。原生语音发送仍需声音插件自己的权限和聊天范围。

## 来源与音色配置（界面调整）

语音音色页先选择本地模型或外接API。本地可使用随附肥鱼引擎，或通过“选择自己的模型”配置 Breeze TTS 2 兼容 GGUF 文件；其他模型格式不能直接使用。模型自带音色与自定义录音采用选项卡切换，不用折叠区域。内置音色提供明亮可爱、自然可爱、温柔，可填写最多100字试听。

外接API单独填写模型和音色ID，可维护最多100个服务音色ID（每行一个），在音色ID输入框选择；不同服务没有统一的音色查询接口，目前为手动维护清单。切换到API会隐藏本地音色库；新合成任务不套用本地参考音色与调音配置。输入试听文本无需再次保存配置。

语音制作与发送进度常驻显示；桌面宽窗口在右侧，窄窗口顺序排列。
