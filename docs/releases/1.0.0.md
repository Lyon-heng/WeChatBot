# WeChatBot 1.0.0

## 下载哪个包

普通用户下载 **Windows 安装版**即可开始配置。便携版是另一种启动方式，两者任选其一。

| 文件 | 用途 |
| --- | --- |
| `WeChatBot-Setup-1.0.0-x64.exe` | Windows 10/11 x64 安装版。双击安装，首次使用推荐此包。 |
| `WeChatBot-1.0.0-portable-x64.zip` | Windows x64 便携版。完整解压，打开根目录的 `WeChatBot.exe`。 |
| `WeChatBot-plugins-all-1.0.0.zip` | 插件合集。在能力目录选择「导入插件总包」，新插件默认关闭。 |
| `SHA256SUMS.txt` | 附件的 SHA-256 校验值。 |
| `VERIFICATION.json` | 打包版本、构建信息与验证记录索引。 |
| `Source code (zip / tar.gz)` | GitHub 自动生成的源码归档，供开发和审阅。 |

单个插件 ZIP 也可在「能力 → 能力目录」直接导入。主包随附人物记忆和人格工作室，其他插件按需下载。

| 单个插件 ZIP | 用途 |

| `cosyvoice-engine-1.0.1.zip` | 接入本地 CosyVoice3 肥鱼语音引擎。 |
| `fish-notebook-1.0.0.zip` | 按人格整理日记。 |

| `local-voice-model-1.0.0.zip` | 选择兼容 Breeze TTS 2 的本地 GGUF 模型。 |
| `memory-evaluation-1.0.1.zip` | 用虚构长对话评测记忆效果。 |
| `memory-events-1.2.1.zip` | 管理聊天中的事件和约定。 |
| `memory-retrieval-1.2.1.zip` | 检索人物档案和聊天记忆。 |

## 本版说明

- 版本字段统一为 1.0.0（桌面端、安装器、部署清单与本目录一致）。
- 仓库迁移到 `Lyon-heng/WeChatBot`，程序内检查更新与项目链接指向该仓库。
- 功能基线为 0.5.6，并包含 `RELEASE_NOTES.md` 中「未发布 · 整曲分离内存修复」一组修改。
- 插件分发目录重建：18 个插件 ZIP 与合集包随本版附件发布，`packages/plugin-distribution/catalog.json` 记录实际字节数与 SHA-256。

## 隐私与数据边界

- 源码与发行包都不包含账号、凭据、聊天数据库、个人人设和已安装插件状态；仓库只保留 `config/wechatagent.example.json` 示例配置。
- 本版不再内置共享的 WorkBuddy 应用 `publishableKey`。首次使用请在设置中填写自己的应用地址（`https://…app.workbuddy.host`）与该应用的 `publishableKey`，密钥由 Windows 当前账户保存。
- 源码中不含开发机绝对路径；临时文件按 `%TEMP%` 运行期解析。

## 已知边界

- 完整收发适配目标仍为微信 `4.1.10.27` x64；其它版本不保证。
- 前台发送模式不发送语音气泡；Hook 模式能力更全但账号风险更高，两种方式均不保证账号安全。
- Windows 打包依赖已审计的二进制基线与本机微信客户端，克隆仓库无法单独重建完整安装器；详见[发行流程](../RELEASE_WORKFLOW.md)。
